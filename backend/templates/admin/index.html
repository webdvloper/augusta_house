Как наполнять витрину. Сначала создайте рубрики (разделы верхнего уровня и вложенные), затем добавьте товары с фото и соберите их в подборки. Подборки с отметкой «На главной» попадают в баннер и блоки главной страницы. Чтобы обновить сайт на GitHub Pages, выполните python manage.py catalog_save и запушьте папку backend/data в ветку main.
